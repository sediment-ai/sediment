# Code of conduct

Be professional and direct. Critique code and ideas, never people.

Not tolerated: harassment, personal attacks, discriminatory language, or
publishing others' private information.

Enforcement: maintainers may edit, hide, or reject contributions and
comments that violate this, and may block repeat offenders. Report
conduct issues privately via GitHub's report-content tools or to the
maintainers.

That's the whole document. If it needs to grow, it will.
